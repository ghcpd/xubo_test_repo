# xubo_test_repo

## Display unique_id values from a JSONL file

Use the provided Python script to print the value of `unique_id` (or any key) from each line of a JSON Lines file.

Usage:

```
python3 display_jsonl_unique_ids.py path/to/file.jsonl
```

Specify a custom key with `-k`:

```
python3 display_jsonl_unique_ids.py -k some_other_key path/to/file.jsonl
```
