# xubo_test_repo

Trip Planner web app

How to run locally

- Use any static server. Example with Python:
  - cd /home/runner/work/xubo_test_repo/xubo_test_repo
  - python3 -m http.server 8000
  - Open http://localhost:8000/index.html in your browser

Features

- Drag & drop cities into 7-day itinerary and reorder within days
- Collapsible day cards with smooth slide animation
- Inline editable notes with blue glow focus
- Summary of total cities and unique countries
- Live JSON preview of itinerary state
