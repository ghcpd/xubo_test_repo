# Chinese Zodiac SPA

This is a simple, responsive single-page web app that displays the 12 Chinese zodiac animals as animated image buttons (using emoji) with a modal popup for details and a language toggle (中文/EN).

Features:
- Dynamic JSON data loading (`data/zodiac.json`)
- Clickable image buttons with hover effects
- Modal popup with name, years, and traits
- Language toggle (Chinese / English)
- Responsive grid layout
- Bonus: Animated modal appearance (fade/slide)

How to run:
1. Option A: Open `index.html` directly in your browser.
2. Option B: Serve locally for best results:
   - `cd` into the repo root and run: `python3 -m http.server 8000`
   - Visit: `http://localhost:8000/index.html`
